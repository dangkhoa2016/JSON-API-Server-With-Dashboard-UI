# Manual Testing

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](README.vi.md)

Curl scripts for manually verifying the API over both **REST** and **tRPC**.

## Layout

| Path            | Description                                                       |
|-----------------|-------------------------------------------------------------------|
| `run-all.sh`    | Runs every script in `rest/` followed by every script in `trpc/`  |
| `rest/*.sh`     | One script per resource/area, hitting the REST API (`/api/...`)   |
| `trpc/*.sh`     | Same coverage, hitting the tRPC API (`/api/trpc/...`)             |
| `output/`       | Log files generated by `run-all.sh` (auto-created, git-ignored)   |

## Prerequisites

Start the API server first so it listens on `http://localhost:3000`.

## Run everything

```bash
bash manual/run-all.sh
```

Output is printed to the terminal and written to `manual/output/run-<timestamp>.log`.

## Run a single script

```bash
bash manual/rest/posts.sh    # REST only
bash manual/trpc/posts.sh    # tRPC only
```

## Point at a different server

Scripts default to `http://localhost:3000`. Override with the `BASE_URL` environment variable:

```bash
BASE_URL=http://localhost:8080 bash manual/run-all.sh
```

## Admin / authenticated scripts

`rest/admin.sh` and `trpc/admin.sh` cover admin endpoints that require a token:

1. Run the script and copy the token returned by the login call.
2. Replace `export TOKEN="..."` in the script.
3. Re-run the script; authenticated calls will use the token.

## tRPC specifics

- Query procedures use `GET`; mutations use `POST`.
- Inputs are serialized with [superjson](https://superjson.org): `?input={"json":{...}}` for GET, `{"json":{...}}` body for POST.

## Script reference

| Script      | Covers                                                       |
|-------------|--------------------------------------------------------------|
| `admin.sh`  | Login, settings (list/get/update/reset), seed and reset data |
| `albums.sh` | CRUD + filter by `userId`                                    |
| `comments.sh`| CRUD + filter by `postId` + full-text search                |
| `photos.sh` | CRUD + filter by `albumId`                                   |
| `posts.sh`  | CRUD + pagination + filter + full-text search + sort         |
| `todos.sh`  | CRUD + filter by `userId` / `completed`                      |
| `users.sh`  | CRUD + filter + wildcard search + full-text search + sort    |
